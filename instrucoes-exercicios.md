# Instruções sobre Exercícios

Neste período, como não temos horas de laboratório associado à
disciplina, os exercícios precisarão ser entregues através de um
repositório git (via GitHub). Veja abaixo como criar e manter
esse repositório para que os exercícios sejam recebidos e
contabilizados a tempo.

## Como criar o repositório

Inicialmente, responda ao formulário enviado pelo classroom.
Depois que você responder, eu criarei um repositório para você
com o nome que você sugerir no formulário e o compartilharei com
você (a menos que já esteja usado ou que você não tenha seguido
as orientações quanto aos nomes que são válidos - veja abaixo). É
através desse repositório que você deve responder os exercícios.

> O convite para o classroom da turma foi enviado por email,
> através do SIGAA.

Para cada exercício, você deve criar um diretório específico. O
nome do diretório será dado no próprio enunciado do exercício.
Crie exatamente igual, para que a coleta possa ser automatizada.
Se você errar o nome, o script pode não coletar sua resposta. Se
isso acontecer, você não receberá a pontuação associada.


## Nome do repositório

Para facilitar a identificação dos repositórios aos alunos, é
importante que sigam as restrições abaixo:

1. o nome do repo tem a forma `nome.sobrenome`;
2. todas as letras devem ser ascii puro (sem acentos);
3. todas as letras minúsculas;
4. apenas um `.` como separador (nenhum outro caractere vale);

IMPORTANTE: você pode escolher livremente os dois nomes usados e
até a ordem em que vai usá-los; mas devem ser nomes que me
permitam associar o nome do repositório a seu nome completo,
facilmente.
